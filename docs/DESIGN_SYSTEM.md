# My Island: рабочий интерфейс

Направление — спокойный школьный кабинет. Морская навигация, светлые поверхности,
бирюзовые действия, компактные списки. Основной характер задают асимметричный знак MI,
цвет навигации и ясная типографика. Иллюстрированный остров в Telegram сохраняется;
рабочие панели используют те же принципы и цвета.

## Токены

Источник реализации: `app/workspace.css`, область `.admin-workspace`.
Legacy не получает этот класс. Не переносить эти правила в глобальные селекторы.

| Токен | Значение | Назначение |
| --- | --- | --- |
| `--ws-ink` | `#193d46` | Основной текст |
| `--ws-muted` | `#526c75` | Вторичный текст |
| `--ws-accent` | `#176f68` | Основное действие, выбор, фокус |
| `--ws-soft` | `#e8f3f0` | Выбранные и вспомогательные поверхности |
| `--ws-line` | `#d6e2e2` | Разделители |
| `--ws-paper` | `#f2f6f5` | Рабочий фон |
| `--ws-surface` | `#ffffff` | Таблицы, формы, панели |
| `--ws-font` | Segoe UI, system-ui, sans-serif | Интерфейс с кириллицей, без загрузки внешних шрифтов |

Навигация: `#163d45`, активный пункт: `#d5ebe3`, текст: `#174c46`.
Шаг отступов: 4 / 8 / 12 / 16 / 24 / 32 px. Радиусы: 7 px у полей и кнопок,
8–10 px у рабочих поверхностей, 12–14 px у диалогов.

## Правила компонентов

- H1: 25–28 px, 650; мобильный H1: 23–24 px. H2: 16–22 px.
- Основной текст и таблицы: 13 px; вторичные подписи: 11–12 px.
  В плотном расписании допустимы 10 px у времени и метаданных, 11 px у предмета.
- Кнопки: 38 px на десктопе, 42–44 px на телефоне. Один основной акцент на задачу.
- `.admin-panel`, `.admin-button`, `.admin-search` — общие поверхности и действия.
  Не добавлять отдельные вариации цветов для справочников и преподавателей.
- Таблицы сохраняют строки; широкие данные прокручиваются внутри контейнера.
- Группы показываются компактными карточками с раскрытием состава на месте.
  На телефоне — две колонки; раскрытый состав получает необходимую ширину.
- Конструктор: первая строка инструментов управляет черновиком и неделей,
  вторая — видом, поиском и сеткой. Сетка и инспектор прокручиваются независимо.
  Пользовательские цвета преподавателей и предметов остаются функциональными.
- Технические проверки и подробности источников — в `details`, с ясной подписью.
- Диалоги центрируются в viewport, имеют ограничение высоты и внутренний scroll.
  Использовать native `dialog` для фокуса, Escape и модальности.
- У каждого поля есть имя; placeholder не заменяет label. Видимый focus обязателен.
  Активная навигация имеет `aria-current`; сообщения — `status` или `alert`.
- Анимации только для обратной связи; учитывать `prefers-reduced-motion`.

## Проверка новой страницы

Открыть 1920×1080, 1366×768 и 390×844. Проверить длинные названия, заполненную
таблицу, пустую выдачу, форму, клавиатуру, закрытие диалога и границы viewport.
Снимать одинаковые состояния до/после. Для записей использовать только изолированную
SQLite в `.local-test`; реальные школьные данные не нужны для визуальной проверки.

## Использованные рекомендации

UI/UX Pro Max: плотность, иерархия, focus и контраст. Рекомендации о hero и CTA
не применяются к рабочей платформе. Frontend Design: осмысленный характер,
единая типографика, минимум декоративных элементов. Vercel Web Interface Guidelines:
семантика, подписи полей, клавиатура, reduced motion и адаптивные границы.
