# Исправления конструктора расписания — 30 октября 2026

Изменения подготовлены для My Island (`Surpd/my-island`). Production не публиковался; миграции и изменения школьных данных не выполнялись.

## Причины и исправления

- Обед раньше исключался из расчёта аудитории как служебная пометка. Теперь явно назначенный обед разрешается по canonical memberships и уступает пересекающимся учебным занятиям. Неизвестный состав блокирует подтверждение, а исторические маркеры без определённого охвата не превращаются в назначение всему классу.
- Режим «Все остальные» мог расширять выбранный административный класс до параллели, а поиск параллели зависел от технического имени. Явные ID классов теперь сохраняют приоритет; поиск параллели использует метаданные и отображаемое имя canonical-класса. В форме можно выбрать исходные классы. Ошибка определения состава не отображается как успешный нулевой результат.
- Массовый пересчёт доступен отдельной командой: весь шаблон, день, класс/группа или устаревшие составы. Preview показывает изменения и нерешённые записи. Одна кнопка подтверждает только проверенные составы через revision CAS и fingerprint справочника. Повтор без изменений не повышает revision. Для недель учитывается дата каждого занятия, включая изменения memberships посреди недели.
- Кружки имеют отдельное размещение в сетке, независимое от участников и каталога. Можно создать «Айкидо» без преподавателя, каталога и участников, с необязательным местом. Пустая аудитория не превращается в весь класс. Clipboard и перенос учитывают `displayClassIds`, создают новый ID при копировании и сохраняют явные аудитории. Архивные записи каталога скрыты при создании; существующие архивные связи остаются видны.
- В frontend и backend введены согласованные ключи кабинетов. `каб. 16`, `каб.16`, `Кабинет 16`, `каб 16` и `16` сравниваются одинаково. Именованные залы и лаборатории не объединяются по сходству названия. Исторические исходные значения не переписываются; сетка и projections используют единое отображение.
- Совместное занятие остаётся одной записью. В колонке показываются локальные классы/учебные группы; полные связи доступны в деталях и подсказке. Пустой roster не скрывает явно заданное размещение. Событие в шаблоне повторяется в созданных из него неделях; событие отдельной недели остаётся в ней.
- Рядом с названием черновика доступен карандаш. Enter сохраняет имя, Esc отменяет, пустое имя отклоняется. Действующий API сохраняет имя с CAS, сохраняя несохранённые занятия в редакторе. Переименование из списка также сохранено.
- Тип занятия отделён от способа ввода. Обед получил короткую форму; создание «Нет урока» скрыто, историческая canonical-семантика сохранена. Ошибки создания отображаются у формы и не очищают введённые данные.
