Для настроек предлагается C, когда один администратор возвращается к конкретной группе параметров. D сокращает переходы при разовой проверке нескольких служб. Для предпросмотра предлагается C на широком экране и верхняя панель D при ограниченной ширине. Компоновки сравниваются на одинаковых состояниях. В Today хронология и исключения остаются параллельными на широком экране. На узком экране исключения появляются перед занятиями. Удаление действующих операций не предложено.

В операционных экранах основной синий используется для выбранных действий, шкал времени и опубликованных интервалов. Светлый сине-серый обозначает фон и незаполненные области. Янтарный выделяет статусы и исключения, требующие проверки. Зелёный используется для подтверждённых состояний и уже опубликованных добавлений. Текстовые подписи сохраняют эти различия без цвета.

На узком экране исключения идут перед хронологией и в порядке обхода с клавиатуры. Семь дат имеют цели минимум 44 × 44 CSS px. Если ширины не хватает, прокручивается только список дат. Покрытие и планирование следующей недели раскрываются по запросу, краткие состояния «Часть кабинетов известна» и «Черновик · проверить адресатов» остаются видимыми. Переход из профиля преподавателя открывает его имя и режим учителя. Исходное изображение Campus подписано как пример экрана выбранной роли.
