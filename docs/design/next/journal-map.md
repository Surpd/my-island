C приоритетен для ежедневных сравнений между работами и тех, кто пользуется журналом как основной рабочей таблицей. D подходит для предметной проверки по одной работе и даёт лёгкий доступ к полной матрице. Действия на удаление отсутствуют. S воспроизводит структуру производственного экрана на общей выборке. Исходные операции источников и сопоставления смоделированы без backend, сети и токенов продакшена.
