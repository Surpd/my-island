# Токены и компоненты My Island

Область применения — административные разделы. [Базовые токены и оболочка](shell.css) служат редактируемым источником для обоих направлений. [Журналы](journals.css), [люди](people.css) и [будущие разделы](future.css) показывают применение на рабочих экранах. Конструктор имеет собственные размеры и палитру преподавателей.

| Роль | Значение прототипа | Применение |
|---|---|---|
| Основной текст | `--ink #202339` | Названия, числа, выбранный пункт бокового меню |
| Пояснение | `--muted #60697c` | Дата, источник, подпись поля |
| Фон / рабочая поверхность | `--bg #f6f8fc` / `--paper #fff` | Область страницы и плоскость данных |
| Разделитель | `--line #dce2ec` | Границы строк, разграничение списка и подробностей |
| Действие | `--blue #285ce0` | Переход, основная команда, клавиатурный фокус |
| Акцент | `--yellow #ffda38` | Активная пиктограмма; светлый оттенок отмечает выбранную работу |
| Фирменная точка | `--coral #d83b23` | Завершение надписи My Island |
| Текст интерфейса | Onest, базовый 14 px | При отсутствии локального шрифта используются Segoe UI и системный sans-serif |

## Рабочие компоненты

| Компонент | Состав и поведение | Критерий приёмки |
|---|---|---|
| Навигация | Значок, подпись раздела, один текущий пункт. Вложенная запись сохраняет активный родительский раздел. | Из профиля виден путь обратно к преподавателям. Клавиатурный фокус заметен. |
| Выбор класса / периода | В А фильтры над данными. В Б выбор занимает отдельную область. Пустая комбинация имеет собственное сообщение. | Меняется и подпись, и содержимое. Записи другого периода не появляются. |
| Матрица | Имя ученика связано с ячейкой. В заголовке работы видны дата и вес. Исходный результат, отсутствие отметки и пересдача читаются текстом. | Цифра 0 и тире различимы. Широкая таблица прокручивается внутри рабочей области. |
| Список и инспектор | Выбранная строка и заголовок подробностей относятся к одному человеку или работе. Выбор следующей строки обновляет детали. | Контекст класса и поиск сохраняются при возврате. На узком экране основные данные доступны без прокрутки всей страницы вбок. |
| Профиль | В А личные поля и вкладки. В Б расписание и назначения привязаны к выбранному человеку. | Предмет, человек и назначение различимы без раскрытия формы. |
| Форма | Поля с явными подписями, основное сохранение и отмена. В прототипе изменения действуют только в текущем окне. | Отмена сохраняет прежнюю запись. После успешного изменения новое значение видно в карточке. |
| Состояние публикации | Словесный статус, версия и период рядом с данными; черновик выделен отдельной областью. | Замена, отмена, черновик и опубликованное расписание различимы без цвета. |
| Виджет | Заголовок и независимый фильтр. В режиме настройки доступны размер, порядок и удаление. | Два экземпляра одного типа могут показывать разные классы. |
