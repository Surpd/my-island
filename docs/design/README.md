# My Island · Визуальная приёмка
Сравните один рабочий сценарий в двух направлениях. В А список и карточка открываются последовательно. В Б выбранная запись остаётся рядом со списком, работой или составом группы.

**Интерактивная версия** — [страница приёмки](index.html). Загрузите [архив ветки](https://github.com/Surpd/my-island/archive/refs/heads/codex/visual-directions.zip), распакуйте и откройте `docs/design/index.html` в браузере. Сеть, установка и учётная запись школы не требуются. GitHub показывает исходный код HTML. Для просмотра прямо на GitHub нажмите любой снимок ниже.

## Решение к обсуждению

Рекомендация — Б для настольных рабочих мест завуча. В журнале можно сменить работу, сохранив матрицу перед глазами. В справочнике можно выбрать другого человека и сразу сверить его назначения. На узком экране предпочтительнее последовательный маршрут А. Главный вопрос для приёмки — хватает ли места на обычном ноутбуке для соседних столбцов журнала при открытой детализации. Это дизайнерская рекомендация, которую предстоит проверить с сотрудниками школы.

## Следующие разделы

[Сегодня](screens/B-today.png) объединяет опубликованные занятия, изменения и отдельный черновик следующей недели. [Нагрузка](screens/B-load.png) сопоставляет минуты по шаблону и публикации. [Аналитика классов и журналов](screens/B-stats.png) разделяет продолжительность занятий и заполненность результатов. В [личном пространстве](screens/B-widgets.png) можно менять порядок, ширину и класс отдельного виджета.

[Настройки](screens/B-settings.png) раскрывают технические сведения по запросу. [Административный preview](screens/B-preview.png) использует исходный Campus выбранной роли. Форму редактирования можно открыть из профиля в обоих направлениях. Прототип хранит изменения в открытом окне.

## После утверждения направления

Каждый пункт — отдельная ветка, worktree и Draft PR с описанием решений, кадрами до и после и браузерными проверками.

1. Общие компоненты, токены, состояния фокуса и правила адаптации.
2. Каталог журналов и оценки. Сверить с действующим журналом периоды, пересдачи, веса, ноль, пустые значения и итоги.
3. Ученики и группы. Проверить возврат к выбранному классу и сохранение поиска.
4. Преподаватели и персональные профили. Проверить назначения и переход к расписанию.
5. Формы, настройки и административный preview. Проверить отмену, сохранение, длинные значения и клавиатуру.
6. Новые разделы по мере готовности серверных данных. Для каждого отдельно проверить происхождение показателей и пустые состояния.

## Проверка прототипов

В Chromium через Playwright проверены страница приёмки, десять основных вариантов и шесть дополнительных экранов при ширине 375, 768 и 1366 px. На этих размерах страницы открываются без ошибок JavaScript и общей горизонтальной прокрутки. Исходные матрицы могут прокручиваться внутри таблицы.

Проверены переключение сравнения с клавиатуры, увеличение снимка и закрытие по Escape, переходы из приёмки к журналу и профилю, фильтр класса и триместра, поиск с сохранением фокуса, показ обеих оценок пересдачи, возвращение к матрице, добавление и перестановка виджета, переход от аналитики к замене в среду и открытие исходного preview преподавателя. Проверка охватывает демонстрационные сценарии Chromium; для решения о внедрении нужна оценка завуча на его обычном устройстве.
