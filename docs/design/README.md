# My Island · Рабочее место завуча

Новая итерация дизайнерской приёмки в PR #51. Для сравнения выберите исходный образец **S**, направление **С · Обзор** или **Д · По задаче**. Все три используют общие синтетические записи соответствующего раздела. Образец S воспроизводит структуру текущего приложения. Подлинные исходные кадры представлены в архиве.

**[Интерактивная страница приёмки](index.html)** · [Редактируемая доска OpenPencil](next/workspace.fig) · [Дизайн-система и внедрение](next/design.md) · [Проверки и независимая критика](next/review.md)

Чтобы пройти сценарий, [скачайте архив ветки](https://github.com/Surpd/my-island/archive/refs/heads/codex/visual-directions.zip), распакуйте и откройте `docs/design/index.html`. Макеты работают локально. На GitHub можно открыть любой снимок в исходном разрешении.
