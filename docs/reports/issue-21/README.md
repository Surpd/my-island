# Редактор занятий My Island

Слева направо в верхнем ряду показаны урок и практикум, в нижнем ряду — консультация и кружок. Снимки сделаны в Chromium на синтетических данных. Каждый снимок показывает редактор в пределах видимой области, включая закреплённое действие «Добавить» или «Сохранить правку».

| Размер браузера | Создание | Повторное открытие после сохранения |
|---|---|---|
| 1366 × 768 | [Четыре формы создания](1366-create.png) | [Четыре формы редактирования](1366-edit.png) |
| 390 × 844 | [Четыре формы создания](390-create.png) | [Четыре формы редактирования](390-edit.png) |

Урок на снимках сохранён очным с кабинетом 17. Практикум, консультация и кружок сохранены в формате онлайн, который включён по умолчанию при создании. Выбор типа сохраняет установленный формат.

Сценарии можно повторить через `npm run test:e2e -- e2e/schedule-constructor-repair.spec.ts --grep 'Issue 21'`. Тесты используют локальный API и тестовую базу с синтетическими преподавателями и группами.
