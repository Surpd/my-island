# Специальные занятия в My Island

## Создание в конструкторе

Выберите ячейку расписания и откройте форму. «Практикум» назначает самостоятельную работу участникам выбранной группы. Поле присутствующего преподавателя можно оставить пустым. В редакторе занятия можно отдельно выбрать ответственного за задание. Очный практикум резервирует кабинет.

«Консультация» резервирует время преподавателя. Ученик из выбранного класса или группы видит её с подписью «по желанию». Одновременный обязательный урок остаётся в его расписании.

Формат «По режиму дня» учитывает расписание класса. «Онлайн» освобождает физический кабинет, сохраняя его значение в черновике. В редакторе можно добавить сведения для подключения. Старое значение кабинета «Онлайн» также распознаётся. У межклассового занятия с разными режимами проверьте формат в редакторе.

Для индивидуальной корректировки откройте «Персональные исключения» в карточке занятия. Укажите основание, выберите учеников и сохраните черновик. Снятие выбора возвращает ученика. История хранит автора, изменение состава и основание. Исключение в шаблоне наследуют новые недели. Исключение, сделанное в неделе, относится к занятию на её дату.

## Лаборатория на одну неделю

1. В конструкторе шаблона откройте «Черновик» → «Лаборатории». Создайте заготовку и сохраните шаблон.
2. Создайте недельный черновик. В том же меню выберите заготовку. Для этой встречи можно изменить тему, день, время, участников, педагогов и место.
3. Нажмите «Посмотреть замещение уроков». Для каждого пересекающегося урока показаны время, переходящие и остающиеся ученики, преподаватели и кабинет. При конфликте можно перейти к связанному занятию, затем вернуться кнопкой «К проверке».
4. После подтверждения кнопкой «Провести на этой неделе» недельный черновик получает новую редакцию. Публикация остаётся отдельным действием.
5. Для отмены откройте «Посмотреть восстановление уроков» и подтвердите отключение. Чтобы изменить состав активированной встречи, отключите её и снова проверьте замещение с новыми участниками.

В примере «Прошлое и настоящее» проходит с 09:55 до 11:40. На экране видны два обычных урока и результат замещения. При частичном замещении оставшиеся ученики продолжают урок со своим преподавателем. Если встреча захватывает часть времени обычного урока, конструктор предлагает уточнить границы. Автоматическое деление такого урока на фрагменты не предусмотрено.

## Личное расписание

Ученик видит обязательную самостоятельную работу, доступную консультацию и одну карточку многослотовой лаборатории. При конфликте посещения каждое известное назначенное занятие получает собственную карточку с предупреждением. Преподаватель видит консультацию как своё занятие. У контактного педагога практикум сопровождается пометкой о его роли.

## Воспроизведение

В консоли из корня репозитория выполните:

```sh
python -m unittest backend.tests.test_special_sessions
npm run test:e2e -- e2e/special-sessions.spec.ts
```

Браузерный тест создаёт синтетический черновик через локальный API, проверяет конфликт, активирует встречу и восстанавливает уроки. Иллюстрации Campus используют синтетические ответы API. Интеграционные тесты отдельно проверяют реальные Canonical-проекции после локальной публикации. Экспорт проверяется на сформированных ячейках и запросах Google Sheets.
