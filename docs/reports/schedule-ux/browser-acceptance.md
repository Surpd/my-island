## Исправление кабинета

1. В проверке открыть конфликт кабинета 309. В карточке видны оба занятия и время. [Кадр](demo-1-room-issue.png)
2. Перейти к информатике. Сетка прокручивается к уроку и выделяет его. Связанная география остаётся доступна из панели проблемы. [Кадр](demo-2-highlight.png)
3. В редакторе выбрать кабинет 310 и сохранить черновик. [Кадр](demo-3-edit.png)
4. Нажать «К проверке». Сохраняются поиск и фильтр «Кабинеты». Проверка редакции 4 показывает, что конфликт кабинета устранён. API подтверждает 310 у информатики и 309 у географии. [Кадр](demo-4-review-restored.png)

## Телефон и клавиатура

В телефоне сначала открывается сетка с подсветкой. Редактор появляется по отдельному действию. Для M43 проверены Enter на кнопке перехода и доступность сфокусированного поля при уменьшении высоты области просмотра до 470 px. [Редактор 390 px](after-editor-390.png) · [Редактор 320 px](after-editor-320.png)

Перенос M23 показывает сохранённое занятие и предложенную ячейку отдельными переходами. Из пустого слота V48 открывается форма с названием «Лаборатория без карточки». Кнопка «К проверке» возвращает к той же позиции сверки без сохранения. Для прежнего слота W48 проверен переход к месту записи. [Предложенный слот 1366 px](after-move-slot-1366.png) · [Предложенный слот 390 px](after-move-slot-390.png) · [Предложенный слот 320 px](after-move-slot-320.png)

## Результаты

- Проверка переходов прошла на 1366, 390 и 320 px. Рабочая копия после всех переходов совпала с исходной редакцией 3. Единственная последующая запись сохранила исправление кабинета как редакцию 4. Основной шаблон совпал с исходным состоянием.
- Отдельный сквозной тест на синтетической базе прошёл все 6 этапов. Проверены сохранение и проверка черновика, обновление состава, массовое редактирование, подтверждённая публикация тестовой недели и расписания ученика и преподавателя.
- Все 10 тестов логики конструктора прошли.
- Архивный браузерный сценарий r45 прошёл на синтетических 386 записях с 41 дополнительным размещением в объединённых классах. Проверены диагностика, контекст парного конфликта преподавателя и мобильное подтверждение. Проверка публикации и восстановления 386 исходных записей также прошла в локальном PostgreSQL 17.11.

## Воспроизведение

Из корня проекта, после установки зависимостей backend и frontend. Если предыдущий локальный стенд на порту 8041 ещё работает, завершите его перед пересозданием тестовой базы.

```bash
python scripts/schedule-regression/local_harness.py --seed-only
python scripts/schedule-regression/issue-navigation-fixture.py
python scripts/schedule-regression/local_harness.py --reuse
```

В отдельном терминале запустить frontend и затем браузерный тест.

```bash
node scripts/schedule-regression/frontend.mjs
PLAYWRIGHT_EXECUTABLE_PATH=/usr/bin/chromium node scripts/schedule-regression/issue-navigation-react.mjs
```

Параметр `--capture` обновляет снимки. Повтор прогона после сохранения правки требует заново засеять фикстуру.
