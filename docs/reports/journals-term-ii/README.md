# Приёмка экранов журнала II триместра

Снимки сделаны в Chromium с одной синтетической книгой при ширине 390 и 1440 пикселей. В локальном приложении работают штатные административный и ученический API. Только чтение Google заменено тестовыми значениями.

| Работы ученика с датой, типом и весом | [Открыть](student-work-390.png) | [Открыть](student-work-1440.png) |
| Работы у завуча, одна раскрыта до оценок | [Открыть](admin-work-390.png) | [Открыть](admin-work-1440.png) |

У математики 13 работ и итог из источника. У истории есть оценка, итог пуст. У физики работа уже заведена, оценки пока нет. Первые восемь работ доступны сразу, остальные — через «Показать ещё». Полная таблица завуча открывается через «Состав и все оценки».
