# Горизонтальная раскладка школьного расписания

Проверена локальная копия архивной редакции **II триместр, r99**. SHA-256 архивного payload — `b1a46caddfe2f9a6f1550f2b07888dcfc0ab799b21eb6ace793d7b7e7f8c01e9`. Для проверки использованы исходные идентификаторы, связи с группами, расписание звонков, размещение кружков, режимы дней и координаты исходных ячеек. На снимках у преподавателей демонстрационные подписи. Исходный набор данных и списки учеников не публикуются.

## Результат за неделю

В проверку вошли все 364 исходных занятия, пять дней, девять звонков и семь параллелей. Одно занятие может появляться в нескольких параллелях или звонках. В дневной сетке получилось 416 карточек в 315 проверенных ячейках. В недельной сетке для каждой ячейки совпал порядок карточек. ## Почему изменились позиции

- Во вторник в 11:50 у обеда осталась исходная ссылка N19. Старый алгоритм отправлял его под историю искусства 9C. Сначала теперь резервируются подтверждённые группы. Обед занимает оставшееся слева место. [Вторник, 9 класс](grade-9-day-1-slot-3.png)
- В пятницу в 12:45 у математики 9B была ссылка L56, у пластики для остальных — M56. Раньше обе карточки попадали в середину. Теперь пластика стоит слева, математика посередине, третье место свободно. В сравнительном прогоне прежней функции на r99 это был второй слот с вертикальной стопкой при свободной позиции. [Пятница, 9 класс](grade-9-day-4-slot-4.png)
- В понедельник сохранены обе схемы. Химия ОГЭ занимает свободную правую колонку по подтверждённой ссылке N7. Это не назначение группе 9C. [11:50](grade-9-day-0-slot-3.png) · [12:45](grade-9-day-0-slot-4.png)
- Курсы по выбору в Sheets раньше всегда получали добавочную строку, кружки выводились отдельно от звонка. Теперь их видно рядом с другими занятиями в их время. При переполнении Sheets расширяет параллель, чтобы сохранить читаемость. [7 класс, четыре одновременных занятия](grade-7-day-2-slot-5.png) · [7 класс, обычный слот](grade-7-day-0-slot-1.png)

### Правила для будущих правок

1. У группы с известной постоянной позицией резервируется своё место. Отсутствующая соседняя группа оставляет просвет. Подтверждённая аудитория занятия имеет приоритет перед историческими копиями назначений. Название предмета не определяет группу.
2. Для остальных занятий можно использовать непротиворечивую ссылку на известную исходную колонку, если место свободно. Сначала размещаются самостоятельные занятия, затем аудитории «Остальные». При равных основаниях используется порядок по содержанию занятия. Идентификатор разделяет только равные по признакам карточки.
3. Два занятия одной фиксированной группы делят её собственное место по горизонтали и получают пометку о совпадении. Дополнительным занятиям при нехватке мест выделяется пространство в той же строке. Сохранённая аудитория при этом не меняется.
4. Параллельный урок нескольких классов и занятие на нескольких звонках сохраняют ссылки на исходную запись. Кружок может иметь классы размещения без обязательных участников. Для карточек без известной параллели предусмотрена отдельная отображаемая колонка.
5. При открытии формы на широком экране измеряются колонка и доступная область сетки с учётом закреплённого столбца времени. При обычной прокрутке повторного центрирования нет. Возврат из онлайн-формата до сохранения восстанавливает кабинет. При превращении урока в практикум можно явно оставить преподавателя присутствующим или сделать ответственным за задание.

Геометрия измерялась в Chromium на настоящем React-компоненте. Скрипт открывает локальную копию, переключает дни, сверяет каждую карточку с планом Sheets, переходит на недельный вид, затем открывает и закрывает редактор. Изменения формы выполняются в памяти браузера. Отдельный штатный E2E-набор работает с локальным API и тестовой SQLite. Google Sheets проверен до формирования ячеек и их диапазонов. Публикация в живую таблицу и проверка на физическом телефоне не проводились.

## Воспроизведение

Из корня проекта после установки зависимостей передайте путь к частному JSON с полями `payload` и `groups`. Предметные тесты без этой копии доступны в обычном наборе.

```sh
node --test components/schedule-lanes.test.mjs components/schedule-constructor-logic.test.mjs
python -m unittest backend.tests.test_schedule_sheet_publishing
node scripts/schedule-regression/lane-week.mjs /path/to/private-copy.json
node scripts/schedule-regression/lane-browser.mjs /path/to/private-copy.json /tmp/island-preview
```

Переменная `PYTHON` позволяет выбрать интерпретатор с backend-зависимостями. Для Chromium поддерживается штатная `PLAYWRIGHT_EXECUTABLE_PATH`. Приватная копия нужна только двум проверкам конкретной недели.
