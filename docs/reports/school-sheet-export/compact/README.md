# Полный день расписания II триместра

Проверка на обезличенной копии r98 с 365 исходными занятиями. В экспорте все классы занимают 1223 px по ширине. Границы классов выделены, подгруппы идут в порядке номера или буквы. Если в слоте одна группа, карточка занимает весь класс.

Все снимки сделаны при 1366×768 и масштабе 100%. В конструкторе ширина сетки 1274 px, высота 396 px. Правая и нижняя границы видны без прокрутки. Экспорт проверен в Chromium по XLSX, скачанному из проверочной Google-книги. Интерфейс Google Sheets запросил вход, поэтому доступное место под его панелями не измерялось.

## Карточки и расписание звонков

| Пример из предыдущей вкладки | Новый результат |
| --- | --- |
| Пятница A45/A46 | A57/A58 показывают 09:00–09:45 и 09:55–10:40 |
| Пятница D45/B46 | D57, B58 и D59 показывают одно длительное занятие с общим цветом и подробностями 09:00–11:40 |
| Четверг B40/F40 | B54 и F54 показывают одно занятие по выбору в обеих параллелях |
| Пятница U45 | U57 и W57 показывают одно совместное занятие для 10-го и 11-го классов |

Нажатие на короткую подпись открывает строку с полным названием, интервалом, группами, преподавателями, кабинетом и причиной отметки. Стрелка слева возвращает в расписание. В экспорте рабочего черновика строка также ведёт к точному занятию в My Island. Знак «?» обозначает уточнение данных, «↔» — совместное занятие, «↳» — продолжение. [Полные карточки](details.png) · [Карточка в конструкторе](constructor-details.png)

Кружки, занятия по выбору и консультации по желанию вынесены в полосу с временем и классами. В проверочном листе 0 примечаний и 365 уникальных исходных ID. Скрытая карта проверена чтением через API и сверена с XLSX. Карточки, повторённые для другой параллели или следующего интервала, ведут к тем же подробностям. Обычные звонки, кабинеты, онлайн, занятия по выбору и порядок 7-1/7-2 и 9A/B/C проверены на структуре r98 и отдельными тестами.
