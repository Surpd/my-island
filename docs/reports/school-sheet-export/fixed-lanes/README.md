Для сравнения использована сохранённая рабочая копия II триместра r98. В тестовой книге у преподавателей коды и рабочие идентификаторы заменены тестовыми. Названия занятий, классы, группы, дни, время и кабинеты взяты из рабочей копии. Предыдущая демонстрация с придуманными названиями была синтетической.

| Понедельник | Слева | По центру | Справа |
| --- | --- | --- | --- |
| 11:50–12:35 | Обед · Остальные | Математика · 9B | Химия · ОГЭ |
| 12:45–13:30 | Математика · 9A | Обед · Остальные | Математика · 9C |

Подтверждённые группы сохраняют позицию даже в одиночном слоте. Координаты исходных ячеек задают место карточки и сохраняют собственную аудиторию занятия. У обоих обедов в этих строках сохранено правило «Остальные». У химии — собственная группа ОГЭ. В Google Sheets API ячейки L7 и M8 школьного оригинала содержат значок 🥨. PDF оригинала передаёт его оранжевой заливкой.

Проверены 365 исходных ID и 418 отображений. Координаты каждой карточки в обезличенной книге сопоставлены с координатами в изолированном экспорте r98. Отдельно по скачанному XLSX сверены значения, цвета, карта исходных занятий и границы дней. В книге одна видимая вкладка. Скриншоты таблицы вырезаны из PDF, сформированного Google Sheets. Снимки конструктора получены в Chromium.

В понедельник три кружка, во вторник два, в среду три, в четверг три, в пятницу один. Каждый день занимает одну строку кружков. Карточки могут занять соседние пустые колонки. При переполнении генератор расширяет колонку так, чтобы каждый кружок оставался виден. На проверенном расписании ширина всей сетки — 1254 px, высота понедельника с шапкой — 451 px. На телефоне расписание прокручивается по горизонтали.
