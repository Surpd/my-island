# Расписание с закреплёнными классами

Верхняя строка листа содержит время и классы. Строка каждого дня подписывает фактический режим по параллелям. В пятницу 5–8-е классы отмечены «Онлайн», а 10-й и 11-й — «СДЭП». Параллельные уроки идут в стабильном порядке. Курсы по выбору, консультации и практикумы стоят в основном расписании в своё время. Одновременные курсы по выбору одного класса идут друг под другом под одним временем звонка. Кружки собраны в отдельном блоке ниже.

| Класс | 5 | 6 | 7 | 8 | 9 | 10 | 11 | Общие |
| --- | ---: | ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| Ширина, px | 124 | 116 | 186 | 139 | 213 | 149 | 162 | 79 |

Предмет, преподаватель, группа при делении и кабинет видны прямо в ячейке. Подписи используют школьные сокращения. У урока для всего класса обозначение класса уже есть в шапке. В актуальной версии пустые поля пропускаются. [Сравнение школьной палитры и новых подписей](../palette/README.md). Неопределённая группа выделена подписью «Группа требует уточнения». В примере среды на 09:00 единственная карточка математики занимает весь 9-й класс и сохраняет подпись 9B. На 11:50 видна разница между учебными группами 7-1/7-2 и административными 9-Ан/9-Д.

Снимки сделаны при 1366×768 и масштабе 100% по XLSX, скачанному из тестовой Google-книги. На обезличенной копии ширина сетки 1254 px, высота среды 589 px и пятницы 638 px. В расчёте по исходным школьным подписям высота сетки среды 667 px, пятницы 674 px. Вместимость с панелями Google Sheets зависит от доступной области окна. Нативный интерфейс не использован для замеров.
