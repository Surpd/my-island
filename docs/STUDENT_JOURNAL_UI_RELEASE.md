# My Island — мобильные оценки и время занятий

Основа: опубликованный `a69ba880519ede8f90efb088f3e2f88f2a50bc58`, GPT Sites version 101. Это **frontend-only** изменение; backend, схема и школьные сведения не менялись. Production автоматически не обновляется.

## Поведение

- «Мои оценки» показывает компактные карточки предметов: период, группа, источник, до трёх последних реальных результатов и только подтверждённые показатели источника. Средние из баллов не вычисляются.
- Каждый исходный журнал остаётся отдельным, даже если предмет совпадает. Триместры, учебные годы и группы не смешиваются; выбор текущих/архивных/всех периодов сохранён.
- Нажатие открывает журнал с работами по датам, исходными результатами, сводными показателями и датой обновления. Пустые работы менее заметны; отсутствующие вес и максимум не выводятся. Реальный ноль и специальные статусы сохраняются; техническая метка `graded` не дублирует числовой результат.
- «К предметам» сохраняет период, прокрутку и фокус карточки.
- Общий `formatLessonTime` / `formatLessonTimeRange` показывает локальное время без секунд и без преобразования часового пояса. Используется в Campus, «Сегодня», расписаниях, карточке преподавателя, мобильном опубликованном расписании и подписях времени конструктора. Значения редактируемых полей не преобразуются.
- Предупреждение о недоступной неделе находится в потоке раздела расписания/«Сегодня». Оно не висит поверх оценок, групп и профиля; отсутствие опубликованных занятий не подменяется тестовыми уроками.

Обычный Mini App и браузерный preview используют одни компоненты. Графика островов, положения зданий, анимации, домашние задания и импорт журналов не менялись.

## Проверки

- Backend: 528 тестов, OK; 8 пропущены, write-enabled PostgreSQL tests против школьной БД не запускались.
- JavaScript: 51/51.
- Playwright: 12/12 в изолированной SQLite и с синтетическими API fixtures. Проверены две ступени журнала, периоды, ноль, баллы/статусы, отсутствие сопоставления, хронология, длинные названия, восстановление прокрутки/фокуса, время с секундами у ученика/учителя, предупреждения, роли и browser preview. Ширины 360/390/430 проверены для списка и деталей.
- TypeScript, lint, production build и положительный identity guard с явным API URL прошли. Guard без API URL ожидаемо отклоняет сборку.
- В разрешённом Supabase read-only обработаны восемь журналов реального ученика 11 класса, включая английский и географию: раздельные источники, предел последних результатов, только исходные сводные показатели, отсутствие подмены пустого результата нулём. Payload передавался в память проверяющего процесса; имена, ID и значения результатов не сохранялись. Это проверка совместимости нормализованных школьных данных с новым представлением, а не production-проверка неопубликованного UI.
- Скриншоты нового интерфейса содержат только синтетические данные. Физический Telegram не проверен.
