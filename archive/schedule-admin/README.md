# Архив ScheduleAdmin

Исходный React-редактор со старым Google ImportReview, статической историей и инспектором сохранён в `schedule-admin.tsx.snapshot`. Пять прежних обработчиков записи — в `legacy-schedule-routes.py.snapshot`; их service-функции остаются в backend. Прежние E2E-сценарии Google ImportReview сохранены в `schedule.spec.ts.snapshot`; активный spec проверяет redirect и HTTP 410. Snapshot-файлы не импортируются и не исполняются.

В активном приложении старый URL перенаправляется в ScheduleConstructor, а пять устаревших мутаций возвращают 410 после проверки администратора. Исторические записи и общие source-процессы не удалены.

Восстановление — отдельная проверенная правка в новой ветке: перенести нужные исходники из snapshot, восстановить только необходимые зависимости и маршруты, провести тест открытия/закрытия без PUT и без изменения revision. Не включать архивный инспектор до устранения его автоматической записи. Не переключать меню отдельно от backend-защит.

Полный локальный source-only backup до консолидации: `.local-test/release-archive/pre-consolidation-source.zip`, SHA256-манифест и working.patch рядом. Эти generated artifacts gitignored; не полагаться на них как на единственную Git-копию. Не применять весь patch поверх дальнейших изменений.

Для отката опубликованного расписания использовать guarded restore нового конструктора, создающий новую неизменяемую версию и аудит. Не удалять историю или данные ради отката оформления.
